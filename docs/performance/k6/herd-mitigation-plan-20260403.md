# Herd Mitigation Plan (2026-04-03)

## 목적
- 이번 라운드의 기본 운영안을 명시한다.

## 현재 결정
- 기본안은 `100ms마다 14명 발급 + jitter`다.
- A/B/C/D 비교 실험은 시간 제약으로 보류한다.

## 시작 가정값
- DB 커넥션 풀: `50`
- 평균 주문 처리 시간: `250ms`
- 이론 최대 TPS: `200`
- 안전 마진 70%: `140 TPS`
- 시작 배치: `100ms마다 14명`

## 적용 메모
- 발급 간격을 1초 단위 일괄 발급이 아니라 100ms 단위로 분산한다.
- jitter를 추가해 같은 배치 안의 주문 API 진입 시점을 더 분산한다.
- rate limit은 이번 기본안에는 포함하지 않는다.
