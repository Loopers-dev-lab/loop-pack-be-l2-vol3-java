## 유저 시나리오

### 브랜드
- 브랜드 상세 정보를 조회할 수 있다.

### 상품
- 상품 목록을 조회할 수 있다.
  - 로그인한 경우 좋아요 여부를 확인할 수 있다.
- 특정 브랜드의 상품 목록을 조회할 수 있다.
- 상품 상세 정보를 조회할 수 있다.
  - 로그인한 경우 좋아요 여부를 확인할 수 있다.

### 좋아요
- 특정 상품에 좋아요를 등록할 수 있다.
- 특정 상품의 좋아요를 취소할 수 있다.

### 주문
- 상품을 주문할 수 있다.
  - 재고가 부족하면 주문할 수 없다.
- 주문 목록을 조회할 수 있다.
- 상세 주문을 조회할 수 있다.

## 유저 기능 흐름

### 상품
- 상품 목록을 조회한다.
  - 로그인 상태이면 상품의 좋아요 여부를 반환한다.
    - 비로그인 상태이면 좋아요 미등록 여부를 반환한다.
  - 파라미터(brandId, sort, page, size)를 확인한다.
  - brandId가 있으면 해당 브랜드 상품만 필터링한다.
  - 정렬 기준에 따라 정렬한다.
  - 페이징하여 반환한다.
  - 등록된 상품이 없는 경우 빈 배열을 리턴한다.
- 상품 상세 정보를 조회한다.
  - 상품이 존재하지 않는 경우 에러를 리턴한다.
  - 로그인 상태이면 상품의 좋아요 여부를 반환한다.
    - 비로그인 상태이면 좋아요 미등록 여부를 반환한다.
  - 상품 정보에 브랜드 정보가 포함된다.

### 브랜드
- 상품에 포함된 브랜드 정보로 상세 정보를 조회한다.
  - 브랜드가 존재하지 않는 경우 에러를 리턴한다.

### 좋아요
- 로그인 사용자만 가능
  - 비로그인시 에러 리턴
- 좋아요를 등록한다.
  - 해당 상품이 존재하는지 확인한다.
  - 이미 좋아요한 상품인지 확인한다.
  - 좋아요가 등록되지 않은 상품이면 좋아요를 등록한다.
- 좋아요를 취소한다.
  - 해당 상품이 존재하는지 확인한다.
  - 좋아요 등록된 상품인지 확인한다.
  - 좋아요 등록된 상품인 경우 취소한다.

### 주문
- 로그인 사용자만 가능
  - 비로그인시 에러 리턴 
- 상품을 주문한다.
  - 상품이 존재하지 않는 경우 에러를 리턴한다.
  - 상품의 재고가 구매 수량보다 부족하면 에러를 리턴한다.
  - 상품의 재고를 구매 수량에 맞게 차감한다.
  - 주문 시점의 상품 정보를 저장한다.
- 주문 목록을 조회 한다.
  - 파라미터(startAt, endAt)를 확인한다.
  - 파라미터 조건에 맞는 목록을 리턴한다.
- 주문 상세를 조회 한다.
  - 주문이 존재하지 않는 경우 에러를 리턴한다.
  - 본인의 주문이 아닌 경우 에러를 리턴한다.
  - 주문 당시의 정보를 리턴한다.

## 관리자 시나리오

### 브랜드
- 브랜드를 등록할 수 있다.
- 브랜드를 수정할 수 있다.
- 브랜드를 삭제할 수 있다.
- 브랜드 목록을 조회할 수 있다.
- 브랜드 상세를 조회할 수 있다.

### 상품
- 상품을 등록할 수 있다.
- 상품을 수정할 수 있다.
- 상품을 삭제할 수 있다.
- 상품 목록을 조회할 수 있다.
- 상품 상세를 조회할 수 있다.

### 주문
- 유저들의 주문 목록을 조회할 수 있다.
- 주문 상세를 조회할 수 있다.

## 관리자 기능 흐름

### 공통
- 커스텀 헤더 X-Loopers-Ldap 의 값을 체크한다.
    - 일치 하지 않으면 에러를 리턴한다.
  
### 브랜드
- 브랜드를 등록한다.
  - 브랜드 정보를 입력받아 등록한다.
  - 등록 성공 시 브랜드 정보를 리턴한다.
- 브랜드를 수정한다.
  - 존재하지 않는 브랜드일 경우 에러를 리턴한다.
  - 브랜드 수정 정보를 입력받아 수정한다.
  - 수정 성공 여부를 리턴한다.
- 브랜드를 삭제한다.
  - 존재하지 않는 브랜드일 경우 에러를 리턴한다.
  - 브랜드 제거 시 해당 브랜드로 등록된 상품들도 삭제한다.
- 브랜드 목록을 조회한다.
  - 파라미터(page, size)를 확인한다.
  - 페이징하여 리턴한다.
- 브랜드 상세 정보를 조회한다.
  - 존재하지 않는 브랜드일 경우 에러를 리턴한다.
  - 브랜드 상세 정보를 리턴한다.

### 상품
- 상품을 등록한다.
  - 브랜드 정보를 확인한다.
    - 존재하지 않는 브랜드일 경우 에러를 리턴한다.
  - 상품 정보를 입력받아 등록한다.
  - 등록 성공시 상품 정보를 리턴한다.
- 상품을 수정한다.
  - 존재하지 않는 상품일 경우 에러를 리턴한다. 
  - 브랜드 정보 수정 시도시 에러를 리턴한다. 
  - 수정 정보를 입력받아 수정한다.
  - 수정 성공 여부를 리턴한다.
- 상품을 삭제한다.
  - 존재하지 않는 상품일 경우 에러를 리턴한다.
  - 상품 삭제 성공 여부를 리턴한다.
- 상품 목록을 조회한다.
  - 파라미터(page, size, brandId)를 확인한다.
  - 존재하지 않는 브랜드일 경우 에러를 리턴한다.
  - 해당하는 브랜드의 상품 목록을 조회한다.
  - 페이징하여 리턴한다.
- 상품 상세를 조회한다.
  - 존재하지 않는 상품일 경우 에러를 리턴한다.
  - 상품 상세 정보를 리턴한다.

### 주문
- 유저들의 주문 목록을 조회한다.
  - 파라미터(page, size)를 확인한다.
  - 페이징하여 리턴한다.
- 주문 상세를 조회한다.
  - 존재하지 않는 주문일 경우 에러를 리턴한다.
  - 주문 당시 저장된 정보를 리턴한다.
