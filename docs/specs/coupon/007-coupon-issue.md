# 쿠폰 발급

## 배경
사용자가 쿠폰을 발급받아 주문 시 할인에 사용할 수 있어야 한다.

## API
POST /api/v1/coupons/{couponId}/issue

## 인증
User

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| couponId | Long | O | Path Variable |

## 응답
| 필드 | 타입 | 설명 |
|------|------|------|
| id | Long | 발급 쿠폰 ID |
| couponId | Long | 쿠폰 ID |
| couponName | String | 쿠폰명 |
| type | String | FIXED / RATE |
| value | Integer | 할인값 |
| status | String | AVAILABLE |
| expiredAt | LocalDateTime | 만료일 |
| createdAt | LocalDateTime | 발급일시 |

## 인수 조건
- [ ] 유효한 쿠폰에 발급 요청하면 200 응답과 발급된 쿠폰 정보를 반환한다
- [ ] 발급 시 해당 쿠폰의 issuedCount가 1 증가한다
- [ ] 동시 발급 요청에도 발급 수량이 정확히 관리된다
- [ ] 쿠폰이 미존재하면 404 응답, 메시지: "존재하지 않는 쿠폰입니다"
- [ ] 만료된 쿠폰이면 400 응답, 메시지: "만료된 쿠폰입니다"
- [ ] 발급 수량이 소진되면 400 응답, 메시지: "발급 가능 수량이 모두 소진되었습니다"
- [ ] 이미 발급받은 쿠폰이면 409 응답, 메시지: "이미 발급받은 쿠폰입니다"
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 발급 수량 차감과 중복 발급 체크는 동시 요청에도 정합성이 보장되어야 한다
- 1인 1매: 동일 쿠폰 템플릿당 사용자 1인 1매만 발급 가능
