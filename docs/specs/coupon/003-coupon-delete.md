# 쿠폰 삭제

## 배경
관리자가 운영 종료된 쿠폰 템플릿을 삭제하고, 미사용 발급 쿠폰을 정리할 수 있어야 한다.

## API
DELETE /api-admin/v1/coupons/{couponId}

## 인증
Admin

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| couponId | Long | O | Path Variable |

## 응답
없음 (200 응답)

## 인수 조건
- [ ] 활성 쿠폰을 삭제하면 200 응답한다
- [ ] 쿠폰 템플릿이 삭제 상태로 변경된다
- [ ] 해당 쿠폰의 미사용(AVAILABLE) 발급 쿠폰도 함께 삭제된다
- [ ] 이미 사용된(USED) 발급 쿠폰은 보존된다
- [ ] 쿠폰이 미존재하면 404 응답, 메시지: "존재하지 않는 쿠폰입니다"
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 쿠폰 삭제와 발급 쿠폰 연쇄 삭제는 원자적으로 처리한다
- 삭제된 쿠폰은 미존재로 처리한다
