# 상품 삭제

## 배경
관리자가 상품을 삭제하여 서비스 노출을 차단할 수 있어야 한다.

## API
DELETE /api-admin/v1/products/{productId}

## 인증
Admin

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| productId | Long | O | Path Variable |

## 응답
없음 (200 응답)

## 인수 조건
- [ ] 활성 상품을 삭제하면 200 응답한다
- [ ] 삭제된 상품은 삭제 상태로 변경된다
- [ ] 이미 삭제된 상품을 다시 삭제해도 200 응답한다
- [ ] 상품이 미존재하면 404 응답, 메시지: "존재하지 않는 상품입니다"
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 삭제 연산은 멱등하게 동작한다 — 이미 삭제된 상품을 다시 삭제해도 정상 응답한다
