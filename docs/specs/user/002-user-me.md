# 내 정보 조회

## 배경
회원이 본인의 정보를 확인할 수 있어야 한다.

## API
GET /api/v1/users/me

## 인증
User (X-Loopers-LoginId + LoginPw 헤더)

## 요청
없음

## 응답
| 필드 | 타입 | 설명 |
|------|------|------|
| loginId | String | 로그인 ID |
| name | String | 이름 (마스킹) |
| birthDate | LocalDate | 생년월일 |
| email | String | 이메일 |

## 인수 조건
- [ ] 본인 정보를 조회하면 200 응답과 회원 정보를 반환한다
- [ ] 이름은 마지막 글자를 *로 마스킹하여 반환한다 (1글자 이름은 전체 *)
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 본인의 정보만 조회 가능하다
