# 비밀번호 수정

## 배경
회원이 본인의 비밀번호를 변경할 수 있어야 한다.

## API
PATCH /api/v1/users/me/password

## 인증
User

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| newPassword | String | O | 8~16자, 영문·숫자·특수문자만 사용 가능 |

## 응답
없음

## 인수 조건
- [ ] 유효한 새 비밀번호로 변경하면 200 응답한다
- [ ] 변경된 비밀번호는 암호화하여 저장한다
- [ ] 새 비밀번호가 현재 비밀번호와 같으면 400 응답, 메시지: "현재 비밀번호와 동일한 비밀번호는 사용할 수 없습니다"
- [ ] 비밀번호에 생년월일이 포함되면 400 응답 (yyyyMMdd, yyMMdd, MMdd 형식)
- [ ] 요청 필드 규칙 위반 시 400 응답
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 현재 비밀번호는 인증 헤더에서 확인한다 (별도 요청 필드 없음)
