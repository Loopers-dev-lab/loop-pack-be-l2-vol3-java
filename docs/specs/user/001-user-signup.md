# 회원가입

## 배경
비회원이 직접 계정을 생성하여 서비스에 가입할 수 있어야 한다.

## API
POST /api/v1/users

## 인증
불필요

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| loginId | String | O | 영문(대소문자)+숫자만 허용, 4~20자 |
| password | String | O | 8~16자, 영문·숫자·특수문자만 사용 가능 |
| name | String | O | 2~20자 |
| birthDate | LocalDate | O | 미래 날짜 불가 |
| email | String | O | 이메일 형식 |

## 응답
| 필드 | 타입 | 설명 |
|------|------|------|
| loginId | String | 로그인 ID |
| name | String | 이름 (마스킹) |
| birthDate | LocalDate | 생년월일 |
| email | String | 이메일 |

## 인수 조건
- [ ] 유효한 정보로 가입하면 200 응답과 회원 정보를 반환한다
- [ ] 비밀번호는 암호화하여 저장한다
- [ ] 이름은 마지막 글자를 *로 마스킹하여 반환한다 (1글자 이름은 전체 *)
- [ ] loginId 중복이면 409 응답, 메시지: "이미 사용 중인 로그인 ID입니다"
- [ ] 비밀번호에 생년월일이 포함되면 400 응답 (yyyyMMdd, yyMMdd, MMdd 형식)
- [ ] 요청 필드 규칙 위반 시 400 응답

## 제약
- 이메일 중복 체크를 하지 않는다
- loginId는 가입 후 변경할 수 없다
