# 브랜드 정보 조회 (User)

## 배경
사용자가 특정 브랜드의 정보를 확인할 수 있어야 한다.

## API
GET /api/v1/brands/{brandId}

## 인증
불필요

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| brandId | Long | O | Path Variable |

## 응답
| 필드 | 타입 | 설명 |
|------|------|------|
| id | Long | 브랜드 ID |
| name | String | 브랜드명 |
| description | String | 브랜드 설명 |
| createdAt | LocalDateTime | 등록일시 |
| updatedAt | LocalDateTime | 수정일시 |

## 인수 조건
- [ ] 활성 브랜드를 조회하면 200 응답과 브랜드 정보를 반환한다
- [ ] 삭제된 브랜드를 조회하면 404 응답, 메시지: "존재하지 않는 브랜드입니다"
- [ ] 해당 ID의 브랜드 데이터가 존재하지 않으면 404 응답, 메시지: "존재하지 않는 브랜드입니다"

## 제약
- 활성 브랜드만 조회 가능하다
- 삭제된 브랜드는 데이터가 없는 것과 동일하게 미존재로 응답한다
