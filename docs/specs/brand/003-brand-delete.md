# 브랜드 삭제

## 배경
관리자가 운영 종료된 브랜드를 삭제하여 서비스 노출을 차단할 수 있어야 한다.

## API
DELETE /api-admin/v1/brands/{brandId}

## 인증
LDAP (X-Loopers-Ldap 헤더)

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| brandId | Long | O | Path Variable |

## 응답
없음 (200 응답)

## 인수 조건
- [ ] 활성 브랜드를 삭제하면 200 응답한다
- [ ] 삭제된 브랜드는 삭제 상태로 변경된다
- [ ] 브랜드 삭제 시 해당 브랜드에 속한 모든 활성 상품도 삭제 상태로 변경된다
- [ ] 브랜드가 미존재하면 404 응답, 메시지: "존재하지 않는 브랜드입니다"

## 제약
- 삭제된 브랜드도 미존재로 처리한다
- 브랜드 삭제와 하위 상품 삭제는 원자적으로 처리한다 (일부만 성공하면 안 된다)
