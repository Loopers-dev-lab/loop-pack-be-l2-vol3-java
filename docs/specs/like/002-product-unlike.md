# 상품 좋아요 취소

## 배경
사용자가 관심이 없어진 상품의 좋아요를 해제할 수 있어야 한다.

## API
DELETE /api/v1/products/{productId}/likes

## 인증
User

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| productId | Long | O | Path Variable |

## 응답
없음 (200 OK만 반환)

## 인수 조건
- [ ] 좋아요한 상품의 좋아요를 취소하면 200 응답
- [ ] 좋아요 취소 시 해당 상품의 likeCount가 1 감소한다
- [ ] 좋아요 취소 시 좋아요 데이터를 물리적으로 삭제한다
- [ ] 좋아요하지 않은 상품에 취소 요청하면 200 응답, 상태 유지 (likeCount 변동 없음)
- [ ] 삭제된 상품에 좋아요 취소하면 200 응답, 좋아요가 존재하면 삭제하고 likeCount를 감소한다
- [ ] 해당 ID의 상품 데이터가 존재하지 않으면 200 응답, 상태 유지
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 좋아요 취소는 물리적 삭제 (soft delete 아님)
- 좋아요 취소 시 같은 트랜잭션에서 상품의 likeCount를 동기 업데이트한다
