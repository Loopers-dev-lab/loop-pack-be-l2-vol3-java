# 상품 좋아요 등록

## 배경
사용자가 관심 있는 상품에 좋아요를 등록하여 나중에 모아볼 수 있어야 한다.

## API
POST /api/v1/products/{productId}/likes

## 인증
User

## 요청
| 필드 | 타입 | 필수 | 규칙 |
|------|------|------|------|
| productId | Long | O | Path Variable |

## 응답
없음 (200 OK만 반환)

## 인수 조건
- [ ] 활성 상품에 좋아요를 등록하면 200 응답
- [ ] 좋아요 등록 시 해당 상품의 likeCount가 1 증가한다
- [ ] 이미 좋아요한 상품에 재요청하면 200 응답, 상태 유지 (likeCount 변동 없음)
- [ ] 삭제된 상품에 좋아요 등록하면 404 응답, 메시지: "존재하지 않는 상품입니다"
- [ ] 해당 ID의 상품 데이터가 존재하지 않으면 404 응답, 메시지: "존재하지 않는 상품입니다"
- [ ] 인증 헤더가 누락되면 401 응답, 메시지: "인증 헤더가 필요합니다"
- [ ] 인증에 실패하면 401 응답, 메시지: "인증에 실패했습니다"

## 제약
- 한 사용자는 하나의 상품에 한 번만 좋아요할 수 있다
- 좋아요 등록 시 같은 트랜잭션에서 상품의 likeCount를 동기 업데이트한다
