# 재고 해제

## 배경
결제 실패 또는 주문 취소 시 점유/확정된 재고를 해제하여 가용 재고를 복원해야 한다. 이는 보상 트랜잭션의 핵심 동작이다.

## API
내부 호출 (외부 API 없음)

## 인증
불필요 (시스템 내부 호출)

## 인수 조건

### 점유 해제 (결제 실패 시)
- [ ] 결제 실패 시 해당 주문의 점유 수량이 주문 수량만큼 감소한다
- [ ] 점유 해제 후 가용 재고가 주문 수량만큼 증가한다
- [ ] 점유 해제 후 총 재고(quantity)는 변하지 않는다
- [ ] 점유 해제와 주문 CANCELED 전이는 같은 보상 트랜잭션에서 처리된다

### 확정 복원 (주문 취소 시)
- [ ] 주문 취소 시 해당 주문의 확정 차감 수량이 주문 수량만큼 감소한다
- [ ] 확정 복원 후 가용 재고가 주문 수량만큼 증가한다
- [ ] 확정 복원 후 총 재고(quantity)는 변하지 않는다
- [ ] 확정 복원과 결제 취소, 주문 CANCELED 전이는 같은 트랜잭션에서 처리된다

### 쿠폰 복원 연계
- [ ] 재고 해제/복원 시 사용된 쿠폰이 있으면 쿠폰도 함께 복원된다
- [ ] 복원된 쿠폰은 다시 사용 가능한 상태가 된다

## 제약
- 보상 트랜잭션은 인프로세스로 즉시 실행한다
- 보상 트랜잭션 실패 시 보정 스케줄러(ST-04)가 후속 처리한다
