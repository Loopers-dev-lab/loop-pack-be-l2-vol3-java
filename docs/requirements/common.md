# 공통

## 범위 제외 사항

| 항목 | 사유 |
| --- | --- |
| 결제 (Payment) | 추후 별도 개발 예정 |
| 주문 상태 관리 | 결제 플로우 확정 후 설계 예정 |

## 유비쿼터스 언어

| 한글 | 영문 | 정의 |
| --- | --- | --- |
| 회원 | User | 서비스에 가입한 사용자 |
| 브랜드 | Brand | 상품을 그룹화하는 입점 브랜드 |
| 상품 | Product | 고객이 탐색하고 주문하는 판매 단위 |
| 재고 수량 | Stock Quantity | 판매 가능한 상품 수량 |
| 좋아요 | Like | 사용자가 상품에 표시하는 관심 표현 |
| 주문 | Order | 사용자의 상품 구매 요청 |
| 주문 상품 | Order Item | 주문에 포함된 개별 상품 항목 |
| 스냅샷 | Snapshot | 주문 시점의 상품 정보 복사본 |

## 공통 용어정리

- **활성**: 삭제되지 않은 정상 운영 상태를 의미한다
- **삭제**: 서비스 노출 차단을 의미하며, 운영 기록 보관을 위해 실제 데이터는 파기하지 않는다
- **미존재**:
    - 데이터가 존재하지 않거나 삭제 상태이거나, 요청자에게 접근 권한이 없는 경우를 의미한다
    - 타인의 리소스 접근 시에도 리소스 존재 여부를 노출하지 않기 위해 동일하게 미존재로 응답한다.
- **데이터 없음**: 해당 ID의 데이터가 DB에 존재하지 않는 경우를 의미한다

## 접근 권한 정의

| 구분 | 인증 방식 | 설명 |
| --- | --- | --- |
| Admin | X-Loopers-Ldap 헤더 | LDAP 인증된 **관리자**만 접근 가능 |
| User (인증 필요) | X-Loopers-LoginId + LoginPw 헤더 | **로그인된 사용자**만 접근 가능 |
| User (인증 불필요) | 없음 | **비로그인 사용자**도 접근 가능 |
