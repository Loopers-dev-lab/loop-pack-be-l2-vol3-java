# 상품(Product)

## User Scenario

- **사용자**: 브랜드에 속한 최신/인기 **상품을 탐색**하여 **구매 결정**을 내릴 수 있다
- **관리자**: 상품을 등록/수정/삭제하여 서비스의 데이터를 최신으로 유지한다

## Feature List

| ID | 기능 명칭 | 대상 | 인증 | API | 설명 |
| --- | --- | --- | --- | --- | --- |
| PR-01 | 상품 등록 | Admin | LDAP | POST /api-admin/v1/products | 특정 브랜드에 속한 신규 상품 등록 |
| PR-02 | 상품 정보 수정 | Admin | LDAP | PATCH /api-admin/v1/products/{productId} | 상품 정보 변경 (소속 브랜드 변경 불가) |
| PR-03 | 상품 삭제 | Admin | LDAP | DELETE /api-admin/v1/products/{productId} | 상품 노출 차단 |
| PR-04 | 상품 목록 조회 | Admin | LDAP | GET /api-admin/v1/products | 관리용 전체 상품 리스트 (페이징) |
| PR-05 | 상품 상세 조회 | Admin | LDAP | GET /api-admin/v1/products/{productId} | 관리용 상품 상세 정보 확인 |
| PR-06 | 상품 목록 조회 | User | 불필요 | GET /api/v1/products | 고객용 활성 상품 탐색 (정렬, 필터) |
| PR-07 | 상품 상세 조회 | User | 불필요 | GET /api/v1/products/{productId} | 고객용 상품 상세 정보 |

## Business Rule

| 규칙 | 설명 |
| --- | --- |
| 삭제 데이터 관리 | 어드민은 삭제된 상품도 조회할 수 있다 |
| 삭제 데이터 노출 차단 | 사용자에게는 활성 상품만 노출한다 |
| 브랜드 필수 소속 | 상품은 반드시 활성 상태의 브랜드에 소속되어야 한다 |
| 브랜드 변경 불가 | 상품 등록 후 소속 브랜드는 변경할 수 없다 |

## Use Case Flow

### [PR-01] 상품 등록

- **Precondition**
    - 해당 브랜드가 존재해야 한다
- **Main Flow**
    1. 관리자가 등록할 상품 정보를 입력하고 등록을 요청한다
    2. 상품을 활성 상태로 등록한다
- **Exception Flow**
    - **[브랜드 미존재]**: 소속 브랜드가 미존재할 경우 등록을 거부하고 "존재하지 않는 브랜드입니다" 안내를 노출한다

### [PR-02] 상품 정보 수정

- **Main Flow**
    1. 관리자가 수정할 상품을 선택하고 정보 수정을 요청한다
    2. 해당 상품의 존재 여부를 확인한다
    3. 상품 정보를 수정한다 (소속 브랜드는 변경할 수 없다)
- **Exception Flow**
    - **[상품 미존재]**: 상품이 미존재할 경우 수정을 거부하고 "존재하지 않는 상품입니다" 안내를 노출한다

### [PR-03] 상품 삭제

- **Main Flow**
    1. 관리자가 삭제할 상품을 선택하고 삭제를 요청한다
    2. 해당 상품의 존재 여부를 확인한다
    3. 해당 상품을 삭제 상태로 변경한다
- **Exception Flow**
    - **[상품 미존재]**: 상품이 미존재할 경우 삭제를 거부하고 "존재하지 않는 상품입니다" 안내를 노출한다

### [PR-04] 상품 목록 조회 (Admin)

- **Main Flow**
    1. 관리자가 상품 목록 조회를 요청한다
    2. 전체 상품을 최신 등록순으로 페이징하여 반환한다
- **Alternate Flow**
    - **[상품명 검색]**: 상품명 키워드로 검색하여 반환한다
    - **[브랜드 필터]**: 특정 브랜드를 선택하여 해당 브랜드에 속한 상품만 필터링하여 반환한다
    - **[상태 필터]**: 활성/삭제 상태별로 필터링하여 반환한다

### [PR-05] 상품 상세 조회 (Admin)

- **Main Flow**
    1. 관리자가 조회할 상품을 선택하고 상세 정보 조회를 요청한다
    2. 해당 상품의 데이터 존재 여부를 확인한다
    3. 해당 상품의 기본 정보와 관리용 데이터를 반환한다
- **Alternate Flow**
    - **[삭제된 상품]**: 삭제 상태의 상품도 조회 가능하며, 삭제 상태임을 표시하여 반환한다
- **Exception Flow**
    - **[상품 데이터 없음]**: 해당 ID의 상품 데이터가 존재하지 않을 경우 조회를 거부하고 "존재하지 않는 상품입니다" 안내를 노출한다

### [PR-06] 상품 목록 조회 (User)

- **Main Flow**
    1. 사용자가 상품 목록 조회를 요청한다
    2. 활성 상품만 조회하여 최신순으로 페이징하여 반환한다
- **Alternate Flow**
    - **[브랜드 필터]**: 특정 브랜드를 선택하여 해당 브랜드에 속한 상품만 필터링하여 반환한다
    - **[정렬]**: 최신순, 가격 오름차순, 좋아요 내림차순 정렬 기준을 변경하여 반환한다

### [PR-07] 상품 상세 조회 (User)

- **Main Flow**
    1. 사용자가 조회할 상품을 선택하고 상세 정보 조회를 요청한다
    2. 해당 상품의 존재 여부를 확인한다
    3. 상품 상세 정보를 반환한다
- **Exception Flow**
    - **[상품 미존재]**: 상품이 미존재할 경우 조회를 거부하고 "존재하지 않는 상품입니다" 안내를 노출한다
