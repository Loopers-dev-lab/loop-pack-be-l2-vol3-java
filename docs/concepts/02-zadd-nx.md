# ZADD NX — 중복 방지 원리

## 핵심 개념

`ZADD NX`는 **member가 존재하지 않을 때만 추가**하는 옵션입니다.
이미 있으면 무시(score 업데이트도 안 함) → 멱등성 보장.

## 동작 비교

```
# NX 없이
ZADD queue 1000 userA   → 추가됨 (score: 1000)
ZADD queue 9999 userA   → score가 9999로 덮어씌워짐 (순서 바뀜!)

# NX 사용
ZADD queue NX 1000 userA   → 추가됨 (score: 1000)
ZADD queue NX 9999 userA   → 무시됨 (score 그대로 1000)
```

## 왜 멱등성을 보장하는가

같은 userId로 몇 번을 호출해도 결과가 동일합니다.
- 네트워크 재시도, 클라이언트 중복 요청이 와도 순서가 바뀌지 않음
- 첫 번째 진입 시각(score)이 항상 유지됨

## 반환값

| 상황 | 반환값 |
|------|--------|
| 새로 추가됨 | 1 |
| 이미 존재해서 무시됨 | 0 |

→ 반환값으로 "처음 진입인지 중복 진입인지" 구분 가능

## 퀴즈 Q&A

**Q. 같은 userId가 1초 간격으로 두 번 대기열 진입을 시도했다. ZADD NX를 쓰면 어떻게 되는가?**
A. 첫 번째 요청만 추가(반환값 1), 두 번째는 무시(반환값 0). 순서는 첫 번째 진입 시각 기준으로 유지됨.
