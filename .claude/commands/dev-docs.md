세션 간 컨텍스트를 유지하기 위한 개발 문서 3파일 패턴을 생성/업데이트한다.

## 생성 파일

`dev/active/` 디렉토리에 아래 3개 파일을 생성한다:

### 1. dev/active/plan.md
- 현재 작업의 전체 계획과 목표
- 구현 순서, 의존 관계
- 완료/미완료 체크리스트

### 2. dev/active/context.md
- 현재 세션에서 파악한 코드 맥락
- 관련 파일 경로와 역할
- 내린 결정과 그 이유
- 남은 의문점

### 3. dev/active/tasks.md
- 다음 세션에서 이어갈 구체적 TODO
- 각 작업의 우선순위
- 블로커/의존성

## 사용 시점

- 긴 작업을 중단할 때
- 세션이 리셋되기 전 컨텍스트를 보존할 때
- 새 세션 시작 시 `dev/active/` 파일을 읽어 맥락 복구

## 규칙

- 이전 `dev/active/` 내용이 있으면 덮어쓰지 않고 업데이트한다
- 완료된 작업의 문서는 `dev/archive/{날짜}/`로 이동할 수 있다
- 현재 작업 중인 파일 목록, 마지막으로 수정한 파일, 다음 할 일을 반드시 포함한다

## 새 세션 복구 방법

새 세션 시작 시 아래 프롬프트로 맥락을 복구한다:
```
dev/active/ 폴더를 읽고 이전 작업을 이어서 진행해줘
```
