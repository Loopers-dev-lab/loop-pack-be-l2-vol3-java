### MCP 연결 실패
"Connection refused"가 보이면:
1. MCP 서버 실행 확인: Settings > Extensions
2. API 키 유효성 확인
3. 재연결: Settings > Extensions > {서비스명} > Reconnect

### 인증 만료
1. OAuth 토큰 갱신 필요
2. Settings > Extensions에서 재인증

2. 서비스 상태 확인
