## 3. 부하 프로파일

```
Stage 1: Warm-up     0 → 50 VU    (30s)
Stage 2: Ramp-up    50 → 100 VU   (1m)
Stage 3: Stress    100 → 200 VU   (30s)
Stage 4: Ramp-down 200 → 0 VU     (1m)
```

- 총 약 3분, 8개 시나리오 (목록 조회 6 + 상세 조회 2), weight 기반 VU 분배
