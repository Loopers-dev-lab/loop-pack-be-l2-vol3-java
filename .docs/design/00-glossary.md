# Glossary

LAST UPDATED: 2026-02-10

| 한국어   | 영어            | 설명                          |
|-------|---------------|-----------------------------|
| 회원    | User          | 서비스를 이용하는 사용자로 상품을 주문하거나 좋아요를 등록할 수 있다. |
| 브랜드   | Brand         | 상품을 제공하는 브랜드로 여러 상품을 가질 수 있다. |
| 상품    | Product       | 브랜드에 소속되어 회원에게 판매되는 물품      |
| 좋아요   | Like          | 회원이 상품에 대해 표시하는 관심 표현       |
| 주문    | Order         | 회원이 상품을 구매하는 행위로 여러 주문 상품으로 구성된다. |
| 주문 상품 | OrderItem | 주문을 구성하는 개별 상품 단위           |
